# Set up package architecture

## Description

Set up the base package architecture for the Type-R Component Library.

## Acceptance Criteria

- Package exports are configured.
- TypeScript is configured.
- Build tooling is configured.
- Source folders are organized.
- Package can be imported by another project.

## Technical Notes

This package must remain CMS-agnostic and should not depend on Sanity, Next.js, or website-specific logic.
